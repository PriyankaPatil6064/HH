# HerHealth

### AI-Powered Women's Health Assistant

HerHealth is an intelligent healthcare platform designed to provide personalized health guidance and support for women. The system leverages Generative AI to deliver symptom-based assistance, menstrual health tracking, wellness recommendations, and conversational support through a modern web interface.

---

## 🚀 Features

* AI-powered health assistant
* Personalized symptom analysis
* Menstrual health and wellness guidance
* Conversational chatbot interface
* Secure and user-friendly experience
* Responsive and modern UI
* Real-time interaction with AI models

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/HerHealth.git
cd HerHealth
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
